# appscmd

KaiOS 3 and up
{:.label.m-0}

In 2021, [Mozilla partnered with KaiOS Technologies] to "modernize the old Boot2Gecko codebase to run atop a modern Gecko so that it can be used by KaiOS as a basis for their future phones", and redesigned WebIDE in the process (currently included in Firefox Developer Edition).

[Mozilla partnered with KaiOS Technologies]: https://wiki.mozilla.org/KaiOS
